# Andex 0.98

- 右侧工作轨迹采用 Aether 的细线与图标时间线样式，保留现有右侧抽屉和左右手势协调逻辑。
- 每次用户输入作为独立任务组，标题直接使用原始输入；单行显示，超长末尾省略，展开输入步骤可读完整内容。
- 任务组与组内步骤独立折叠。初始展开最新任务，旧任务折叠；手动展开的任务可同时保持展开。
- 工具详情分为“命令”和“结果”，使用圆角代码块、限制高度、上下滚动与独立复制。普通输入与回复按正文展示。
- 折叠状态保存在列表外，搜索、抽屉开关、工具状态更新不会清空用户选择。搜索期间显示命中的任务与步骤。
- 工具进度按 ID 更新，保留原始步骤位置，避免重复记录或停留在旧的运行状态。
- Android 与 iOS 使用同一分组和展示实现；iOS 的工具与推理片段顺序同步按时间线顺序整理。
- README 新增 Yukie（tangnanbai）的贡献者头像与账号链接，保留原项目和第三方署名。

版本：Android 0.98 / 24；iOS 0.98 / 30。
