# Andex 隐私政策

维护者：Yukie（GitHub：tangnanbai）。更新日期：2026 年 11 月 6 日。

## 本地保存

Andex 在应用数据目录保存对话、模型配置、角色、终端文件及长效记忆。导出文件保存在你选择的位置。清除应用数据或卸载可能删除本地内容，建议先导出备份。

## 模型和第三方服务

发送消息时，对话上下文、角色设定、相关记忆，以及你选中的附件会传给你配置的模型服务。语音输入默认使用豆包输入法非官方 ASR：按住时将音频直接流式发送至其在线服务，松手等待最终结果后填入草稿。没有中转后端，不默认长期保存原始录音。在线服务会处理音频及必要的设备注册信息，可用性和额度由服务端决定。网页搜索、GitHub 和扩展会连接相应服务，其处理规则由对应服务提供方决定。

语音设备凭据保存在设备私有存储中：Android 使用 Keystore 加密，iOS 使用钥匙串，均不随语音缓存导出。0.99 升级会清除旧火山语音服务地址和凭据，保留模型配置。

API 凭据用于请求你配置的服务。请勿在记忆中保存密码或 API Key。自动记忆会拒绝可识别的凭据格式，但无法保证识别所有敏感内容；你可以查看、关闭和清空记忆，并自行检查导出文件。

## 手机权限

存储权限用于访问你授权的文件；麦克风用于按住说话；无障碍用于读取屏幕、点击、输入和滑动；ADB 使用你连接的调试通道；悬浮窗用于显示后台任务进度。已授权的 Agent 操作可能把屏幕信息作为上下文发送给所选模型。可在系统设置及 Agent 模式中关闭相关能力。

无障碍连接开启时会使用前台通知保持服务。系统强行停止、撤销权限或厂商省电策略仍可能中断连接。

## 诊断与更新

应用包含诊断日志、经过用户同意后启用的使用情况分析能力，以及 GitHub 更新检查。诊断导出会进行脱敏；反馈前请仍检查文件中是否存在个人信息。GitHub 更新检查会向 GitHub 发起网络请求。

## 你的控制

你可以删除对话和记忆、修改服务地址、撤销权限，或清除应用数据。导出的 Markdown 记忆为明文，请自行妥善保管。
