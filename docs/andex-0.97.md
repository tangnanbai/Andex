# Andex 0.97

- 通用设置将主题色和背景色拆成两行圆形色点，均提供黑、白及七种参考色。点击立即应用，设置可保存和随备份导入导出。
- 保留旧版双色配色；首次修改其中一色时保留另一色。“恢复默认”回到浅色粉白、深色粉黑。
- 主题色作用于界面文字、图标、按钮、提示、高亮和描边；文字会根据背景及卡片表面调整明暗，避免浅色或同色组合看不清。
- AI 正文继续使用中性文字色，暗背景为白色、亮背景为黑色。
- 按钮和弹窗使用半透明磨砂表面，高对比度或不支持模糊时回退为实色。
- 全部设置页改用同底色与细横线分隔，模型提供方表单、后台进度和扩展配置保持同样的层次；弹窗仍保留磨砂材质。
- 左栏顶部搜索、设置和模式切换按钮增加独立间距，透明按钮底色跟随当前背景，避免固定黑色。
- 火山 ASR 配置新增服务地址与检测连接按钮，使用短静音校验鉴权和资源访问，不需要录音权限。
- 未唤醒键盘时，短按输入框唤醒键盘，长按录音；键盘打开后长按交给文本选择与粘贴。
- 录音、取消和识别错误提示改为输入框上方的独立浮层，文字自动换行，位置限制在屏幕内，避免被输入框圆角裁切。
- 对话右下角长按切换话题改为无底板的文字滚轮；当前项放大、高亮，相邻项逐级缩小和变淡，拖动时平滑过渡，松手跳转。
- 上下文用量改为主题色圆环，点击弹出进度条、千分位用量、百分比和当前模型。
- 无障碍提醒分别检查系统授权与服务连接状态。权限关闭需连续确认八秒；权限开启但未连接有一分钟恢复时间。回到前台重新开始观察，不累计后台样本。
- 已授权服务自动恢复后关闭失效提醒；读不到授权状态时不推断权限已关闭。
- 本版同时包含上游扩展性能、日志脱敏、模型服务、Alpine 网络、虚拟显示和推理轨迹方面的适配，见 `UPSTREAM_SYNC_2026-11.md`。

Android 通过 Gradle 构建与单元测试后安装真机验证；iOS 的共享设置和原生入口同步更新，需要在 macOS 上另行编译与实机验证。
