# 模型标识、生图参数与余额

本次版本保持 0.99，Android build 28。

## 模型标识

- 回复下方原来的统计按钮显示实际回复模型的图标，点击仍打开统计。
- 轨迹任务与记录根据本次回复的模型标识显示图标；生图工具显示实际生图模型。
- 历史记录读取已有的 `provider` / `model` 或 `piAssistantMessage`，分块回复按响应组补齐。没有模型信息的旧记录使用中性图标。
- `@` 可以紧接中文、英文、数字或标点输入；只有选择完成的 `@「渠道 / 模型」` 才改变请求模型，普通邮箱不会改变请求路由。

## 图片生成

在设置中启用至少一个生图模型后，文本 Agent 获得 `generate_image` 工具。用户要求生成图片时，模型可以直接调用，默认优先当前渠道的 image2，再使用其他已启用的生图模型。停用的渠道和模型不会提供给工具。

直接 `@` 选择生图模型与工具调用使用同一生成模块。

示例：

```text
设计一个猫咪图标，512x512，PNG 格式，透明背景。
生成一张 16:9 的 2K 桌面壁纸。
```

工具参数：

| 参数 | 用途 |
| --- | --- |
| `prompt` | 完整绘图描述 |
| `model_key` | 可选，指定已配置的生图模型 |
| `size` | 像素宽高，例如 `1024x1024` |
| `output_format` | `png`、`jpeg`、`webp` |
| `background` | `transparent`、`opaque`、`auto` |
| `resolution` | `1K`、`2K`、`4K` |
| `aspect_ratio` | 比例，例如 `16:9` |
| `quality` | `auto`、`low`、`medium`、`high` |

显式工具参数优先于提示词中识别出的参数。OpenAI 图片生成和编辑接口传入对应字段；Gemini 使用 `generationConfig.imageConfig`，OpenRouter 使用 `image_config`。Gemini / OpenRouter 的格式和透明背景要求保留在提示词中，不能保证服务端提供像 OpenAI 图片接口一样的格式、透明背景或任意像素尺寸控制。

透明背景默认请求 PNG；透明 JPEG 在发请求前拒绝。返回 PNG 原样保存、展示，不转换为 JPEG 或填充白色。PNG 文件本身如果没有透明像素，客户端不会自动抠图。支持单张 32 MB 内图片。不把原图 Base64 写入会话记录。

每次工具执行只发起一次生图请求，失败不自动重试计费。文本模型是否主动调用工具仍取决于其工具调用能力；也可 `@` 生图模型直接生成。

## V2Api 余额

仅对配置地址 `https://v2api.top/...` 启用适配，保留 DeepSeek 原有支持。

1. `/api/status` 读取站点展示币种、额度单位与汇率，不发送 API Key。
2. `/api/usage/token/` 读取令牌额度，存在 `user_quota` 时优先展示账户额度。
3. 必要时兼容 `/v1/dashboard/billing/subscription` 与 `/v1/dashboard/billing/usage`，使用总额度减已用额度；usage 按分换算。
4. 无限令牌且不提供账户额度、查询失败、币种/单位不明确时隐藏余额。查询不跟随重定向，不把 Key 发往其他站点。
