# 0.99 / build 27：模型指定、生图与记忆界面

## 使用

- 顶部模型下拉按配置的 API 名称分组。
- 输入 `@` 可搜索渠道名称或模型 ID，选择后插入 `@「渠道 / 模型」`。每条消息指定一个模型，只影响该次请求，不改变会话默认模型。
- 生图支持 GPT Image / DALL-E 的 Images 接口、Gemini 图片模型的 generateContent，以及 OpenRouter 图片响应。图片保存到工作区 `.andex-generated`，聊天记录只保存文件引用。
- 上传参考图时使用图片编辑请求；不支持的服务端能力会显示实际错误。生成失败不自动重试，避免重复计费。
- 图片响应目前限单张 8 MiB，与现有聊天图片加载上限一致。此限制不影响 Markdown 记忆导入。
- 长效记忆点击条目进入全屏查看与编辑。保留单条删除和右上角全部清空，两者均二次确认。
