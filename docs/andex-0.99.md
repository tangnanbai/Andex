# Andex 0.99 交付记录

日期：2026-11-06。包名 `com.android.andex`，版本 `0.99`，版本码 `25`。本轮功能统一进入 0.99。

## 对话与界面

- 右上角角色控件固定距右边缘 20dp；可用宽度达到 520dp 时展开头像和角色名称，长名称省略。竖屏保持圆形头像；模型和余额位于左侧，不决定角色控件的位置。
- 模型胶囊按当前显示名称收紧；下拉菜单按最长模型 ID 测量，受可用空间约束，并为余额、角色保留空间。旋转时重新测量弹窗宽度。
- 旋转清除旧输入焦点并隐藏键盘，不自动唤起键盘。
- 左右栏的搜索在现有标题位置展开；关闭侧栏后收起搜索并清空关键词。搜索键盘的 IME 间距不再传给背后的对话内容。
- 收起键盘不再切换输入框底部间距和占位文字，避免末帧跳动。
- 右下角话题轨道保持固定的手势坐标原点；越过底部松手仍可选择最后一项，横向离开才取消。预览使用磨砂背景。
- 工作轨迹保持任务分组；步骤缩进、字号缩小，折叠时有单行预览。每次打开展开最新任务并定位到最新步骤，随后手动上滑不被持续抢回底部。

## 设置、权限与记忆

- 深色模式使用纯黑；浅色模式恢复最近选择的非黑背景。颜色按亮度从浅到深排列，去除恢复默认按钮。
- 角色提示词上方提供清空和粘贴。关于页移除网站入口，GitHub 和隐私政策使用本仓库，版本直接显示版本号。
- 无障碍保留系统授权状态，在手机控制启用时维持前台服务连接；区分系统已授权和服务已连接。系统强制停止、厂商电池管理或用户撤销权限仍可能中断连接。
- 每轮读取磁盘中的最新记忆；达到上下文 80% 时自动压缩，成功摘要写入长效记忆。记忆更新归一化去重。
- 长效记忆逐条展示、展开、编辑和删除；删除或清空先弹窗确认。刷新、导入、导出位于同一行。Markdown 导入和保存不设文件大小、字数或条目数量的产品限制，仍拒绝凭据内容；完整保存与单次注入上下文的预算分开。导入成功立即刷新，失败显示提示。
- 对未被用户改动的旧内置记忆扩展进行哈希识别、原子升级；用户自定义代码、删除标记和记忆数据保留。

## 在线语音

默认服务为“豆包输入法非官方 ASR”，按用户提供的参考源码独立实现，不集成输入法 UI，不使用火山付费 ASR，不要求安装 Python。

旧火山语音地址、App ID、API Key、Access Token 在读取和导入设置时清除，模型提供方密钥保留。按住时流式发送 Opus，中间文字只预览，松开后等待最终整句一次性回填；上滑取消，唤起键盘后使用系统长按粘贴。

修复了取消时连接可能未可靠关闭、设置检测与录音可能同时连接、错误详情被丢弃的问题。现在不同入口共用会话锁和拒绝冷却，取消时在不可取消的清理区尝试结束会话、关闭连接并强制释放；快速再次录音等待旧连接清理。

历史一次 StartSession 收到 `40200011`，其原始错误详情当时被解析器丢弃，无法确认该历史拒绝的完整原因。后续同一设备、同一 token 的参考客户端和原生客户端均能识别，不能把历史拒绝直接判为密钥失效。现在保留脱敏后的服务端原因、阶段和业务码，未采用换身份绕过拒绝的方式。

真实联网验证：取消一次已启动的会话后，用相同凭据重新识别 8 秒中文音频，12 个中间事件，最终文本：

> 1993 年 2 月 23 日上午，四川省安岳县安源乡五村彭家姑嫂 5 人进城购置衣服。

含取消清理在内耗时 10,829ms。语音协议、并发限制、冷却、取消清理、整句回填及真实网络共 14 项定向测试通过。参考来源、许可和协议见 [语音接入说明](doubao-ime-asr.md)。

## 体积优化

仅支持 ARM64，删除不再使用的 x86 环境资产，启用 R8 和资源压缩，对演示数据中的重复字符串做无损字典去重。没有删减手机功能。

逐字节核对确认 ARM64 Termux bootstrap、ADB/7zip 工具包、Alpine rootfs 与 0.98 一致；两个演示目录恢复后的 JSON 结构也与 0.98 一致。第三方声明和新增 Opus 许可随包保留。最终 APK 的体积、摘要和验证结果记录在本地 `reports/0.99`。

最终构建成功：`Andex-0.99.apk` 为 64,484,802 字节（61.50 MiB），较 0.98 的 151,452,192 字节减少 57.42%。SHA-256：

```text
048ce29e1e32b660f438fccc2b44710dff58697b57a06e676ffe6677586cfe8e
```

签名证书与现有安装相同，支持覆盖安装保留数据。构建日志仍存在现有 Kotlin / R8 元数据兼容警告，未通过新增 suppression 掩盖；最终构建和包检查已通过，本轮优化包已覆盖安装并完成下述真机 UI 验证。

## 本轮 UI 与记忆补修

- 录音光晕改为应用窗口底部绘制的短椭圆渐变，延伸到屏幕底边；语音错误、取消和权限提示使用 Toast。

- 手动导入支持 UTF-8 / UTF-16 BOM，文件读写在后台线程进行；取消选择保留已有记忆。
