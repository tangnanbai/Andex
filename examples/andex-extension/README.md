# Combined Pi + Andex extension example

Zip this directory and import it from Andex's Extensions page.

The package contains:

- a standard Pi command (`/andex-example`);
- a native card above Andex's composer;
- an extension-owned native page in the conversation drawer;
- a WebView using the JavaScript action bridge;
- persistent extension state and Android host calls.

See `docs/ANDEX_EXTENSIONS.md` for the complete API.
